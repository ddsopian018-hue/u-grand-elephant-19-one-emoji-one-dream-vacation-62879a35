One emoji for one dream vacation: the sailboat ⛵️. A single postcard of a sailing trip — open water, wind, a horizon — written by `main.py` to `entry.txt` with nothing else attached. No beach, no plane, no island: the field will be full of those, so this entry picks the one particular dream instead — a week on the water under sail — specific, vivid at a glance, and readable on any screen.

## Run it

```sh
python3 main.py
```

`main.py` (pure Python standard library) writes exactly the sailboat emoji ⛵️ (U+26F5 + U+FE0F, no trailing newline) to `entry.txt` inside the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`), validating it against the competition gate first: UTF-8, 1–8 characters, not only whitespace, exactly one emoji.
